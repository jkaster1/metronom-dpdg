# Метроном ДПДГ

Визуальный метроном для ДПДГ (EMDR — десенсибилизация и переработка движением глаз): точка бегает влево-вправо по экрану под заданным темпом, помогая «гонять глаза» в ритме.

**Одна HTML-страница, без зависимостей и сборки — работает офлайн.** Просто откройте `index.html` в браузере.

## Возможности

- Темп движения: 10–240 переходов в минуту (переход — от одного края до другого)
- Время одного запуска: 1 секунда – 60 минут
- Серии: количество запусков (1–100) с настраиваемым перерывом между ними
- Размах движения (20–95% ширины экрана) и размер точки (3 варианта)
- Тихий щелчок на каждом краю (Web Audio)
- Полноэкранный режим (кнопка «На весь экран»)
- Пауза (кнопка, Пробел или Esc), автопауза при скрытии вкладки
- Параметры можно менять прямо во время движения
- Настройки сохраняются в браузере (localStorage)

## Горячие клавиши

- **Пробел** — запуск / пауза
- **Esc** — пауза и выход из полноэкранного режима

## Дисклеймер

Это вспомогательный визуальный инструмент для ДПДГ, а не самостоятельная терапия.
